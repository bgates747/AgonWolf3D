- The profile uses non-ADL `bbcbasic.bin`. BBC BASIC starts correctly, and

  ```basic

  ```

- Confirmed the working automatic startup sequence. MOS must load the
  interpreter image while `/bin` is current, then change to MapMaker's
  directory before transferring control with `RUN`:

  ```text
  SET KEYBOARD 1
  cd /bin
  load bbcbasic.bin
  cd /mapmaker
  RUN . MAPMAKER.BBC
  ```

  Directly invoking `bbcbasic.bin` starts its interactive prompt, so later
  autoexec lines are not processed as intended.
